# Continuous Integration Design

## Goal

Add one minimal GitHub Actions workflow that verifies the plugin against its locked dependency graph.

## Triggers

Run on pushes to `main`, pull requests targeting `main`, and manual dispatch.

## Environment

Use Ubuntu, Node.js 22, and pnpm 11.22.0. Cache the pnpm store through `actions/setup-node`.

Because pnpm 11 applies a 24-hour package maturity policy by default and DSH rc.8 is newer than that at the time of this change, set `pnpm_config_minimum_release_age=0` only in the CI job. The frozen lockfile remains authoritative and no repository or user-level pnpm policy is changed.

## Checks

1. Install with `pnpm install --frozen-lockfile`.
2. Run `pnpm test`.
3. Run `pnpm typecheck`.
4. Run `pnpm build`.

The workflow intentionally omits version matrices, coverage publishing, releases, and deployment integrations.
