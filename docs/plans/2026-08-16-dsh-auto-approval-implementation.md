# DSH 自动审批实现计划

1. 建立 Settings schema、凭据引用和独立 Responses 客户端。
2. 构造可信/不可信证据，恢复精确工具调用，并实现响应一致性检查。
3. 注册审批 waterfall、按权限预设门控、记录审计事件并实现 turn 级熔断。
4. 提供同源 Web 设置接口，支持设置并发修订和密钥保留/替换/清除。
5. 在 settings.plugin.item 注册“DSH 自动审批”折叠设置卡，并将推理强度做成仿 DSH 的自绘深色下拉菜单。
6. 用本地假 Responses 服务覆盖允许、拒绝、重试、无效响应和超时路径。
7. 构建后安装到 Web Profile，重启 DSH，并验证设置卡与权限预设。
