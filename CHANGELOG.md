# Changelog

All notable changes to this project are documented in this file.

## 0.1.0 - 2026-08-20

- Add independent model-backed review for DSH approval requests.
- Embed the Codex Guardian risk and authorization policy.
- Add Responses API and OpenAI-compatible Chat Completions support.
- Add bounded evidence collection, secret redaction, audit logging, and circuit breaking.
- Add Web settings, credential management, connectivity testing, and policy editing.
- Support DSH 0.1.0-rc.6 through rc.8, with rc.8 used by development and CI.
